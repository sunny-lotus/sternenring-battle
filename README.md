# 星環バトル試作

更新：2026-11-08。シュテルネンリングのバトルを、自分で操作して試す試作。
本番のRPG（STERNENRING_RPG_CORE）には入れていない。数値はすべて仮の値。

## 開き方

`index.html` をダブルクリック。ネット接続・サーバーは不要。

## もとにしたデータ

OneDrive／ドキュメント／ChatGPT／物語／outputs／sr-battle-sandbox（2026-11-07のバトル相談の試算）
- trio-trial.cjs：計算式・技・ナハトのフォーム・追撃／反撃・ブレイク
- five-trial.cjs：五人の持ち込み構成（標準／反撃／追撃）・支援・ボス
- normal-encounter-presets.json：五人期の通常戦（敵HP150・気力45）
- 一組交代：1ターン1組、入った人は行動可、下がった人は支援休み、ブレイク中は交代不可

計算部分（js/engine.js）は試算プログラムを移したもの。同じ条件の144戦で、試算と同じ経過になることを確認した（違いは「前線全滅で終わるか」だけ）。

### 溜め攻撃（緊張感ありのみ）

- 敵が1ターン力を溜める（そのターンは攻撃しない）。敵が光り、画面上に予告が出る。
- 次のターンに大技。ボスは前線全員へ（気力削り55・威力120）、敵三体は一人へ（気力削り90・威力170）。大技は味方をブレイクさせうる。
- 溜め中か、大技の前にブレイクさせれば止まる。
- 溜める時期：ボスは2・5・8…ターン目。敵三体は一体ずつずらして溜める。
- 数値は data.js の `SR.tunes` にまとめてある。

### 自動対戦での確認（各相手×3構成×15戦）

| 相手 | おまかせのみ・交代なし | 簡単な交代あり |
|---|---|---|
| 通常戦 | 全勝・約6ターン・だれかが体力20%前後まで減る | 全勝・約5.6ターン |
| 加入期ボス | 勝率18% | 全勝・約14ターン・最低体力25%前後 |
| 全体攻撃ボス | 勝てない | 全勝・約21ターン |
| 炎耐性ボス | ほぼ勝てない | 全勝・約16ターン |

自動の方針は、溜めている敵を狙わない単純なもの。人が狙えばもっと早く勝てるはず。

## 気になっている点（次の候補）

- ボス戦が14ターン以上と長め。長いと感じたらボスの体力を下げる。
- 全体攻撃ボスは約21ターンの耐久戦。
- 敵の絵は仮。キャラの絵は錬金工房の立ち絵を使用。

## 見やすさ版の仕様（2026-11-08 相談で決定・同日実装、ユーザー確認待ち）

実装メモ：狭い画面（スマホ・縦長）では立ち絵の代わりに顔の絵を使う。行動中の文は盤面の下に出し、同じ文をログにも残す。交代は行動開始まで取り消せる（支援の気力は払い戻して決め直す）。未入力の人は行動開始時に防御。試算どおりモードの計算が試算と同じことを再確認済み。

ユーザーの希望：キャラの位置（前衛・後衛）を分かりやすく。コマンドをすっきり。交代とコマンドの順番を自分で選べる。画面が縦に長い、キャラと文字が小さい、何が起きたか分からない、技の違いが分からない。パソコン・スマホ両方、コントローラーも使いたい。

## 状態付与の仕様（2026-11-08 相談で決定）

属性ではなく「状態を付ける」しくみ。状態そのものの効果は小さく、目的は **コンボ** と **気力を削る下準備**。

| 状態 | 由来の雰囲気 | 効果（小さめ・仮の数値） |
|---|---|---|
| 燃焼 | 炎 | ターンの終わりに最大体力の3%が減る |
| 裂傷 | 風・斬撃 | 行動するたびに最大体力の2%が減る |
| 凍結 | 水・氷 | 受けるダメージが1割増える |
| 目眩 | 光 | 与えるダメージが1割減る |
| 感電 | 雷 | 行動が遅くなる（速さ−12） |
| 暗闇 | 闇 | 攻撃が1割の確率で外れる |

- 状態そのものは気力に関わらない。
- **敵ごとの弱点**：「燃焼中は崩れやすい」のように、決まった状態の間は気力の削れ方が1.5倍。
- **状態を活かす技**：その状態の相手に1.5〜1.7倍。
- **ターン数**：技ごとに決まっている。同じ状態をもう一度付けると足し算で延長、最大6ターン。ターンの終わりに1減る。
- **表示**：状態は描いたアイコン（絵文字は使わない）＋残りターン数。技の枠の色は種類（攻撃＝赤／守備＝青／回復・補助＝緑）、付ける状態と活かす状態はアイコンで示す。
- 状態は「緊張感あり」でだけ働く（「試算どおり」は試算と同じ計算のまま）。
- ナハトの技は斬撃なので裂傷。闇や光の属性をナハトの設定に結びつけることはしない。
