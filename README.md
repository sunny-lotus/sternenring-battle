# 星環バトル試作

更新：2026-11-08。シュテルネンリングのバトルを、自分で操作して試す試作。
本番のRPG（STERNENRING_RPG_CORE）には入れていない。数値はすべて仮の値。

## 開き方

`index.html` をダブルクリック。ネット接続・サーバーは不要。

## もとにしたデータ

OneDrive／ドキュメント／ChatGPT／物語／outputs／sr-battle-sandbox（2026-11-07のバトル相談の試算）
- trio-trial.cjs：計算式・技・ナハトのフォーム・追撃／反撃・ブレイク
- five-trial.cjs：五人の持ち込み構成（標準／反撃／追撃）・支援・ボス
- normal-encounter-presets.json：五人期の通常戦（敵HP150・気力45）
- 一組交代：1ターン1組、入った人は行動可、下がった人は支援休み、ブレイク中は交代不可

計算部分（js/engine.js）は試算プログラムを移したもの。同じ条件の144戦で、試算と同じ経過になることを確認した（違いは「前線全滅で終わるか」だけ）。

### 溜め攻撃（緊張感ありのみ）

- 敵が1ターン力を溜める（そのターンは攻撃しない）。敵が光り、画面上に予告が出る。
- 次のターンに大技。ボスは前線全員へ（気力削り55・威力120）、敵三体は一人へ（気力削り90・威力170）。大技は味方をブレイクさせうる。
- 溜め中か、大技の前にブレイクさせれば止まる。
- 溜める時期：ボスは2・5・8…ターン目。敵三体は一体ずつずらして溜める。
- 数値は data.js の `SR.tunes` にまとめてある。

### 自動対戦での確認（各相手×3構成×15戦）

| 相手 | おまかせのみ・交代なし | 簡単な交代あり |
|---|---|---|
| 通常戦 | 全勝・約6ターン・だれかが体力20%前後まで減る | 全勝・約5.6ターン |
| 加入期ボス | 勝率18% | 全勝・約14ターン・最低体力25%前後 |
| 全体攻撃ボス | 勝てない | 全勝・約21ターン |
| 炎耐性ボス | ほぼ勝てない | 全勝・約16ターン |

自動の方針は、溜めている敵を狙わない単純なもの。人が狙えばもっと早く勝てるはず。

- 全体攻撃ボスは約21ターンの耐久戦。

## 状態付与の仕様（2026-11-08 相談で決定）

属性ではなく「状態を付ける」しくみ。状態そのものの効果は小さく、目的は **コンボ** と **気力を削る下準備**。

| 状態 | 由来の雰囲気 | 効果（小さめ・仮の数値） |
|---|---|---|
| 燃焼 | 炎 | ターンの終わりに最大体力の3%が減る |
| 裂傷 | 風・斬撃 | 行動するたびに最大体力の2%が減る |
| 凍結 | 水・氷 | 受けるダメージが1割増える |
| 目眩 | 光 | 与えるダメージが1割減る |
| 感電 | 雷 | 行動が遅くなる（速さ−12） |
| 暗闇 | 闇 | 攻撃が1割の確率で外れる |

- 状態そのものは気力に関わらない。
- **敵ごとの弱点**：「燃焼中は崩れやすい」のように、決まった状態の間は気力の削れ方が1.5倍。
- **状態を活かす技**：その状態の相手に1.5〜1.7倍。
- **ターン数**：技ごとに決まっている。同じ状態をもう一度付けると足し算で延長、最大6ターン。ターンの終わりに1減る。
- **表示**：状態は描いたアイコン（絵文字は使わない）＋残りターン数。技の枠の色は種類（攻撃＝赤／守備＝青／回復・補助＝緑）、付ける状態と活かす状態はアイコンで示す。
- 状態は「緊張感あり」でだけ働く（「試算どおり」は試算と同じ計算のまま）。
- ナハトの技は斬撃なので裂傷。闇や光の属性をナハトの設定に結びつけることはしない。
- 実装（同日）：付ける技＝ナハト（崩し斬り・返し斬り・誘い斬り・踏み込み斬り→裂傷）、ヴォルト（連射・分散連射→感電、術式妨害→暗闇）、フレア（炎系→燃焼）、セレナ（連弾→凍結）、リヒト（破陣剣→目眩）、コモン（衝撃→目眩、衝撃波→裂傷）。活かす技＝断ち込み（裂傷中1.6倍）・捨て身斬り（凍結中1.6倍）・術式妨害（感電中1.5倍）・炎撃（燃焼中1.6倍）・灰燼（燃焼中1.7倍）・決着の一閃（目眩中1.6倍）。
- 敵の弱点：通常の敵A〜C＝燃焼・裂傷・感電、甲殻獣＝感電、星獣・癒し手＝裂傷、疾風獣・炎獣＝凍結、氷獣・子獣＝燃焼、術士＝目眩、加入期ボス・双子の大獣＝目眩、全体攻撃ボス・炎耐性ボス＝凍結（ボスの弱点は控えのリヒト・セレナの状態にして、交代の意味を出した）。敵からの状態：疾風獣・双子＝裂傷、炎獣＝燃焼、氷獣＝凍結、術士＝暗闇。
- **付与技を増やした（同日・「付与できるのは1個だけじゃない、バランスは任せる」）**：各キャラ2つ＋コモン2つ。ナハト＝裂き払い（裂傷3）・目潰し斬り（暗闇2）、ヴォルト＝放電弾（感電3）・閃光弾（全体・目眩1）、フレア＝焼き付け（燃焼4）・熱波（全体・燃焼2）、セレナ＝氷結弾（凍結3）・氷霧（全体・凍結1）、リヒト＝閃光（目眩3）・斬光（裂傷2）、コモン＝目くらまし（暗闇3）・痺れ針（感電2）。単体は装備コスト3、全体は4〜5。活かす技も追加：破陣剣（凍結中1.4倍）・返し斬り（暗闇中1.5倍）。自動対戦では付与を使う編成は標準構成と同じくらいの強さで、強いボスに効く（全体攻撃ボス29→18ターン）。
- **さらに見直し（同日）**：付与専用技は「いつでも使える」をやめ、編成で選ぶふつうのユニーク技（装備コスト3）にした。最初からある標準・反撃・追撃の構成には入っていないので、使うときは「自分で編成」で選ぶ。
- **見直し（同日・ユーザー「付与が多すぎる」）**：今ある技に付与を付けるとバランスが崩れるので、付与は各キャラの**付与専用技**だけにした。緊張感ありのとき、編成コストなしで使える（威力は弱め）。ナハト＝裂き払い（裂傷3）、ヴォルト＝放電弾（感電3）、フレア＝焼き付け（燃焼4）、セレナ＝氷結弾（凍結3）、リヒト＝閃光（目眩3）。今ある技の付与は外した（例外：コモンの衝撃で暗闇2）。活かす技はそのまま（断ち込み・捨て身斬り・連射〔感電中1.5倍〕・炎撃・灰燼・決着の一閃）。上の「付ける技」の一覧は古い。
- ボス級の体力1.5倍はやめた（付与が減ってコンボで短くなりすぎることがなくなったため）。自動対戦：おまかせのみだとボス戦はほぼ負け、付与技と交代を使えば全勝で13〜17ターン・最低体力2〜3割。
- 調整：燃焼・裂傷は1回の上限（18・12）を付けた（体力の多いボスで強くなりすぎたため）。それでもコンボでボス戦が短くなりすぎたので、緊張感ありのボス級（ボス3種と双子の大獣）は体力1.5倍。自動対戦（交代あり）で加入期ボス約11ターン・最低体力4割強、双子の大獣約12ターン・約3割。

## オクトラ（大陸の覇者）から学んだこと（2026-11-08 相談）

しくみだけを参考にし、名前・キャラ・絵はまねしない。
1. ブースト：入れた（2026-11-08、緊張感ありのみ）。決めたこと：たまるのは最大2・1回の行動で2まで使える・回数は増えない。
   - ターンのはじめに1つたまる（最初は1）。使ったターンの次はたまらない。ブレイク中・倒れている人はたまらない。控えにいてもたまる。
   - 使える技：攻撃・回復・気力回復。威力（体力ダメージ・回復量）が ×1.5（1つ）／×2（2つ）。崩す力（気力ダメージ）は上がらない。
   - 崩す力も上げる案は、自動対戦でボスが約10ターンで終わり強すぎたのでやめた。威力だけだと、交代ありのおまかせでボス 約25→15ターン、いちばん減った人の体力 約23%（緊張感は残る）。
   - おまかせ：ブレイク中の相手への攻撃では全部使う。2たまっていたら1つ使う。
   - 数値は data.js の SR.tunes.tense.boost（max・mult・kd）。
2. **控えの回復：採用**。緊張感ありでは、控えにいる人（ブレイク中を除く）がターンの終わりに最大体力の5%回復する。自動対戦では効き目は控えめ（ボス戦で最低体力が数%上がる程度）。
3. 弱点は状態のしくみだけ（武器・属性の弱点は作らない）。
